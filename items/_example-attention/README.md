# Example item (structural only)

This folder shows the shape of a processed item (level 3). No real
extracted text is included, and folders starting with `_` are ignored by
`shelf.py`. Delete it whenever you like.

A real item has a page file for every pdf page (`pages/0001.md` ...
`pages/0015.md`), and its original lives in `raw/` (here it would be
`raw/vaswani2017-attention-is-all-you.pdf`, dropped in as
`inbox/papers/attention.pdf`).
