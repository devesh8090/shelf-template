# Example item (structural only)

This folder shows the shape of one processed item (level 3), as it would
sit in a library at `items/_example-attention/`. No real extracted text is
included; folders starting with `_` are ignored by `shelf`.

A real item has a page file for every pdf page (`pages/0001.md` ...
`pages/0015.md`), and its original lives in the library's `raw/` (here it
would be `raw/vaswani2017-attention-is-all-you.pdf`, dropped in as
`inbox/papers/attention.pdf`).
